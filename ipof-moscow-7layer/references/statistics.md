# เกณฑ์สถิติ

## 1. ค่าสถิติ

| ค่า | วิธีคำนวณ | สูตร Excel |
|---|---|---|
| X̄ รายข้อ | ค่าเฉลี่ยคะแนนดิบของข้อนั้น | `AVERAGE(ช่วง)` |
| S.D. รายข้อ | ส่วนเบี่ยงเบนมาตรฐานแบบตัวอย่าง (n − 1) | `STDEV.S(ช่วง)` (บันทึกเป็น `_xlfn.STDEV.S`) |
| X̄/S.D. รายด้าน | คะแนนดิบ **ทุกค่า** ของทุกข้อในด้าน | `AVERAGE(ช่วง1,ช่วง2,…)` / `STDEV.S(ช่วง1,ช่วง2,…)` |
| X̄/S.D. ภาพรวม | คะแนนดิบทุกค่าของทุกข้อ | เช่นเดียวกัน |
| X̄ ข้อกำหนดที่รวมหลาย N | คะแนนดิบทุกค่าของ N เหล่านั้น | เช่นเดียวกัน |

**ห้ามเฉลี่ยค่าเฉลี่ยรายข้อ** (ค่าจะต่างเมื่อจำนวนผู้ตอบรายข้อไม่เท่ากัน และ S.D. ผิดเสมอ)
ค่าที่ขาด (ไม่ติ๊ก/ติ๊กเกิน) ไม่นับในตัวหาร และรายงาน n รายข้อ — ห้ามเติมค่า

รายงานทศนิยม 2 ตำแหน่ง ทั้งตาราง บทความ และ Excel (รูปแบบ `0.00`)

## 2. การแปลผล (มาตราส่วน 5 ระดับ)

| ช่วงค่าเฉลี่ย | ระดับ |
|---|---|
| 1.00–1.80 | น้อยที่สุด |
| 1.81–2.60 | น้อย |
| 2.61–3.40 | ปานกลาง |
| 3.41–4.20 | มาก |
| 4.21–5.00 | มากที่สุด |

แปลผลจากค่าที่ปัด 2 ตำแหน่งแล้ว (ค่าที่รายงานกับระดับต้องสอดคล้องกัน)

## 3. คำถามเลือกหลายข้อ / ข้อมูลทั่วไป

จำนวนผู้เลือก และร้อยละ = จำนวน ÷ ผู้ตอบทั้งหมด × 100 (ไม่ใช่ ÷ จำนวนครั้งที่เลือก) ระบุใต้ตารางว่า "เลือกได้หลายข้อ ผลรวมอาจเกินร้อยละ 100"

## 4. MoSCoW

1. เรียงค่าเฉลี่ยข้อกำหนดจากมากไปน้อย
2. แบ่งด้วยจุดแบ่งที่ระบุชัดเจนก่อนดูผลรายข้อ (`moscow_cutoffs`) เช่น Must ≥ a, Should ≥ b, ต่ำกว่า b = Could และเขียนเหตุผลของจุดแบ่งในบทความ
3. ทดสอบ Must ทุกข้อ: "ถ้าไม่มีข้อนี้ ระบบยังตอบคำถามหลัก (ที่ถามผู้ใช้ตอนเริ่มงาน) ได้หรือไม่" ได้ → ลดเป็น Should
4. ข้อมูลหรือเงื่อนไขที่ข้อ Must ต้องใช้ (`depends_on`) → Must ด้วย
5. Won't Have This Time กำหนดจากขอบเขตการพัฒนารอบนี้ ไม่ใช่คะแนน และยังอยู่ในทะเบียนข้อกำหนด
6. **ห้ามแก้ค่าเฉลี่ยของผู้ใช้** บันทึก `moscow_score` (ตามคะแนน) และ `moscow_final` พร้อม `moscow_reason` ทุกข้อที่ต่างกัน
7. ระบุในตาราง MoSCoW ว่า "ลำดับในตารางไม่ใช่ลำดับการพัฒนา"

## 5. การเห็นชอบของผู้เชี่ยวชาญ

- เกณฑ์ผ่าน: เห็นชอบตั้งแต่ร้อยละ 80 → จำนวนขั้นต่ำ = ⌈0.8 × k⌉ (k = 5 → 4; k = 7 → 6; k = 9 → 8)
- ผ่าน → "ถึงเกณฑ์ (x/k)"; ไม่ผ่าน → ปรับเป็นระดับที่ถูกเสนอมากที่สุด และเขียน "ปรับตามเสียงข้างมาก (x/k)" โดย x = จำนวนเห็นชอบ
- คะแนนเสนอเท่ากัน → ผู้วิจัยตัดสินพร้อมเหตุผล และรายงานว่าเสมอ
- ห้ามเรียกการเห็นชอบ 3 ใน 5 ว่า "ผ่านเกณฑ์ร้อยละ 80"
- แยกข้อที่ถึงเกณฑ์ ออกจากข้อที่ปรับตามเสียงข้างมาก ในตารางและบทความ
