# โครงสร้างตารางและไฟล์ Excel

ตัวเลขทุกค่าในตารางมาจาก Excel ที่ผ่าน `verify_excel.py` แล้ว และต้องตรงกันทุกไฟล์

## 1. ตารางวิเคราะห์ข้อกำหนด 7 ตาราง (เอกสารประกอบเล่มสารนิพนธ์)

| ตาราง | ชื่อ | คอลัมน์ |
|---|---|---|
| 1 | ผลวิเคราะห์ปัญหาและความต้องการ (n = …) | รหัส, รายการ, X̄, S.D., แปลผล — แยกส่วน P และ N ตามด้าน พร้อมแถวรายด้าน/ภาพรวม (พื้นสี) |
| 2 | ความสัมพันธ์ P–N | P, N, เหตุผล |
| 3 | การสังเคราะห์ข้อกำหนด | รหัสข้อกำหนด, ข้อกำหนด, มาจาก N (ค่ารายข้อของแต่ละ N), X̄ ข้อกำหนด (pooled), S.D., เหตุผลการรวม |
| 4 | การจำแนก FR/NFR และกลุ่มหน้าที่ | รหัส, ข้อกำหนด, ประเภท, กลุ่ม G1–G4 (NFR "–"), คำกริยาหลัก |
| 5 | การจัดลำดับ MoSCoW | รหัส, ข้อกำหนด, X̄, ระดับตามคะแนน, ระดับฉบับสุดท้าย, เหตุผล — เรียง M S C W แล้วตามค่าเฉลี่ย หมายเหตุ "ลำดับในตารางไม่ใช่ลำดับการพัฒนา" |
| 6 | ผลประเมินความเหมาะสมของข้อกำหนดโดยผู้เชี่ยวชาญ | รหัส, ข้อกำหนด, X̄, S.D., แปลผล, เห็นชอบ (x/k), ผล "ถึงเกณฑ์/ปรับตามเสียงข้างมาก" |
| 7 | สรุปจำนวนข้อกำหนด | ประเภท FR/NFR × กลุ่ม × ระดับ M/S/C/W พร้อมแถวรวม |

แนบรูป IPOF ท้ายเอกสาร

## 2. ตารางในบทความ (4 ตารางข้อมูล + 1 ตารางสถาปัตยกรรม)

| ตาราง | เนื้อหา |
|---|---|
| 1 | ปัญหาและความต้องการ (X̄, S.D., แปลผล) |
| 2 | P–N–รหัสข้อกำหนด–กลุ่ม–MoSCoW–หลักฐาน (ค่าเฉลี่ย) |
| 3 | ผลประเมินสถาปัตยกรรมรายด้าน (ผู้เชี่ยวชาญครั้งที่ 2) |
| 4 | ผลประเมินข้อกำหนด (ผู้เชี่ยวชาญครั้งที่ 2) |
| 5 | จำนวนข้อกำหนดตามประเภท FR/NFR กลุ่ม และระดับ |

ส่วนที่ไม่อยู่ในบทความ (รูป IPOF ตารางผลรายครั้ง เกณฑ์ยอมรับทุกระดับ) → ไฟล์แยกสำหรับเล่มสารนิพนธ์ **ไม่ทำเป็นภาคผนวกในบทความ**
ตารางใช้ "ตารางที่ n" เรียง 1..n และอ้างในเนื้อหาให้ตรง (รูปแบบตารางตามคู่มือวารสารที่ผู้ใช้ระบุ ถ้าเป็น JDTAIA ใช้ `jdtaia-ieee-document`)

## 3. ไฟล์ Excel (สร้างด้วย `build_excel.py`)

| ไฟล์ | แผ่น |
|---|---|
| ผู้ใช้ (`--mode user`) | สรุปผล, ข้อมูลทั่วไป, ข้อมูลดิบ-ช่องเลือก, ข้อมูลดิบ, ค่าเฉลี่ยรายด้าน, การเลือกฟังก์ชัน, คำตอบปลายเปิด |
| ครั้งที่ 1 (`--mode expert1`) | สรุปผล, ข้อมูลผู้เชี่ยวชาญ, ข้อมูลดิบ, ค่าเฉลี่ย, ยืนยัน MoSCoW, ความเห็นโดยรวม, เหตุผลรายข้อ, คำตอบปลายเปิด, สังเคราะห์ประเด็น |
| ครั้งที่ 2 (`--mode expert2`) | สรุปผล, ข้อมูลผู้เชี่ยวชาญ, ข้อมูลดิบ-คะแนน, ค่าเฉลี่ย-สถาปัตยกรรม, ค่าเฉลี่ย-ข้อกำหนด, การยืนยัน, ความเห็นโดยรวม, ข้อเสนอแนะ, สังเคราะห์ประเด็น |

กติกา
- ทุกค่าคำนวณด้วยสูตร ข้อมูลนำเข้าตัวอักษรสีน้ำเงิน แถวรวม/รายด้านพื้นสี ฟอนต์ TH Sarabun New
- แผ่น "ข้อเสนอแนะ" แยกคอลัมน์ category เป็น "ชื่นชม/ยืนยัน" กับ "เสนอเพิ่ม/ปรับ" และ action (ระบุ "เพิ่มหลังการประเมิน" ถ้านำไปปรับ) — Claude จัดประเภทจากข้อความจริงแล้วใส่ใน `project.json` → `round2.suggestions` ก่อนสร้างไฟล์
- แผ่น "สังเคราะห์ประเด็น" มาจาก `round1.synthesis` / `round2.synthesis` (ประเด็น ผู้เสนอ การตัดสินใจ นำไปปรับที่)
- recalculate แล้วต้องไม่มี error และตัวเลขตรงกับการคำนวณแยก (`verify_excel.py`) ทุกครั้ง
- ห้ามพิมพ์ตัวเลขผลลัพธ์ลงช่องแทนสูตร
