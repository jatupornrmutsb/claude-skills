# การกระจายแบบไทย (Thai Distribute) และช่องไฟ

ข้อควบคุมคุณภาพหลักของ Skill — ปัญหาช่องไฟไทยมักมองไม่เห็นจาก XML ต้องดูภาพหน้าจริงเสมอ

## 1. ใช้การจัดแนวแบบใด

| ข้อความ | ค่า `w:jc` |
|---|---|
| เนื้อความ/เอกสารอ้างอิงที่มีภาษาไทย, หัวข้อระดับสาม | `thaiDistribute` |
| เนื้อความอังกฤษล้วน (เช่น Abstract) | `both` |
| ชื่อบทความ ผู้แต่ง สังกัด หัวข้อ 1./1.1 ชื่อตาราง | `left` |
| ชื่อรูป สมการ | `center` |
| ค่าตัวเลข/รหัสสั้นในตาราง | `left` หรือ `center` ตามคอลัมน์ ห้ามกระจาย |
| ข้อความยาวในเซลล์ตาราง | พิจารณา `thaiDistribute` เฉพาะเมื่อเซลล์กว้างพอ ไม่ทำให้ช่องไฟยืด |

## 2. ตรวจก่อนแก้ (เรียงลำดับ)

1. ภาษาของย่อหน้า (ไทย / อังกฤษล้วน / ปน)
2. ฟอนต์ 4 ช่องของทุก run และ `bCs`/`szCs` (run ฟอนต์ต่างกันในบรรทัดเดียวทำให้ระยะไม่เท่ากัน)
3. ระยะตัวอักษร `w:spacing w:val` ใน `rPr` (ค่าติดลบ = บีบ), สัดส่วน `w:w` (≠100), `w:position`, `w:kern`
4. การย่อหน้า `w:ind`, แท็บ `w:tab` ในข้อความ, ช่องว่างซ้ำ
5. จุดขึ้นบรรทัดเอง `w:br` เดิม
6. อักขระแฝงเดิม (U+200B, U+200C, U+200D, U+2060, U+FEFF, U+00AD)

```bash
python scripts/docx_audit.py ไฟล์.docx   # ดูรหัส CHAR_SPACING CHAR_SCALE HIDDEN_CHAR MULTI_SPACE MANUAL_BREAK NOT_THAI_DIST
```

## 3. วิธีแก้ที่อนุญาต (เรียงจากควรใช้ก่อน)

1. ตั้ง `w:jc` ให้ถูกตามตารางข้อ 1 และให้ Word ตัดคำอัตโนมัติ
2. คืนระยะตัวอักษร/สัดส่วนที่ผิดปกติเป็นค่าปกติ (`apply_layout.py --reset-char`) — เว้นรูปแบบที่มีเหตุผล เช่น ตัวยก/ตัวห้อยในสูตร, หัวตารางที่ตั้งใจบีบเพื่อให้พอดี (ตรวจภาพก่อน; ถ้าก้ำกึ่งให้ถามหรือรายงาน)
3. รวม run ที่แตกฟอนต์ให้ฟอนต์เดียวกัน (`--fonts`)
4. ลบช่องว่าง/แท็บที่ใช้ดันขอบ — ในงานจัดรูปแบบอย่างเดียวนี่คือการแก้ข้อความ ต้องแจ้งและแยกรายงาน
5. **กำหนดจุดขึ้นบรรทัดเฉพาะจุด** เป็นทางเลือกสุดท้าย เมื่อบรรทัดหนึ่งถูกยืดผิดปกติ: ต้องไม่ตัดกลางคำ ไม่ทำให้บรรทัดก่อนจุดตัดสั้นจนถูกยืด และแจ้งผู้ใช้ว่า "ถ้าแก้เนื้อหาภายหลัง จุดนี้ต้องตรวจใหม่"

## 4. ห้าม

- **ห้ามแทรก zero-width space (U+200B) หรืออักขระแฝงใดๆ ทั่วเอกสาร** เพื่อช่วยตัดคำ — แสดงเป็นกรอบสี่เหลี่ยมในบางโปรแกรม/PDF ทำให้ค้นหา คัดลอก และตรวจคำผิดพัง (`text_diff.py` และ `render_check.py` ตรวจจับ)
- ห้ามใช้ช่องว่างหรือแท็บจำนวนมากบังคับให้ขอบเสมอกัน
- ห้ามขึ้นบรรทัดเองทุกบรรทัดเป็นวิธีมาตรฐาน
- ห้ามกระจายชื่อบทความ ชื่อผู้แต่ง หัวข้อ ชื่อรูป หรือค่าสั้นในตาราง
- ห้ามสรุปว่าช่องไฟถูกเพียงเพราะตั้ง `thaiDistribute` ในไฟล์แล้ว

`apply_layout.py --strip-hidden` ลบอักขระแฝง **ที่มีอยู่เดิม** ได้เมื่อผู้ใช้อนุญาต (ไม่เปลี่ยนตัวอักษรที่มองเห็น) ต้องรายงานจำนวนที่ลบ

## 5. บรรทัดที่ต้องตรวจเป็นพิเศษ

บรรทัดที่มีไทยปนกับ: คำอังกฤษ (Must, Should, Could), รหัส (NFR07, DR11), ตัวเลขทศนิยม, วงเล็บ, เลขอ้างอิง [n], เครื่องหมาย –/—, URL/DOI ยาว
(ตัวอย่างเหล่านี้ใช้อธิบายรูปแบบเท่านั้น ไม่ใช่ข้อมูลวิจัย)

อาการที่ต้องหาในภาพหน้า:
- ช่องว่างระหว่างคำห่างผิดปกติในบรรทัดก่อน URL/รหัสยาว
- บรรทัดสุดท้ายของย่อหน้าถูกยืดเต็มบรรทัด
- รหัส/ตัวเลขแตกข้ามบรรทัด (เช่น "NFR" | "07", "4." | "25")
- คำไทยถูกตัดกลางคำ (เช่น "งานพื้น" | "ฐาน")
- สระ/วรรณยุกต์ลอยหรือซ้อนผิดตำแหน่ง (มักเกิดจากฟอนต์ทดแทน)

URL/DOI ยาวในคอลัมน์ 7.5 ซม.: ยอมให้ขึ้นบรรทัดที่ `/` หรือ `.` ได้ ห้ามแทรกช่องว่างในลิงก์

## 6. ข้อจำกัดของการเรนเดอร์ (ต้องบอกผู้ใช้)

- **LibreOffice ไม่แสดง `thaiDistribute` แบบเดียวกับ Word** (จากการทดสอบ เนื้อความไทยแสดงเหมือนชิดซ้าย) และใช้พจนานุกรมตัดคำไทยต่างจาก Word จึงยืนยันได้เพียง: ไม่มีอักขระแฝง ไม่ล้นขอบ ฟอนต์/ขนาด/ตัวหนาถูก ไม่มีระยะตัวอักษรผิดปกติ
- การยืนยันช่องไฟกระจายไทยและจุดตัดคำจริงต้องเปิดใน **Microsoft Word** (เช่น ผ่าน computer use บนเครื่องผู้ใช้ หรือขอให้ผู้ใช้ส่งภาพหน้าจอ) ถ้าทำไม่ได้ให้ระบุในคำตอบว่า "ยังไม่ได้ยืนยันช่องไฟกระจายไทยใน Word"
- ไม่มีฟอนต์ TH Sarabun New ในเครื่องเรนเดอร์ → การตัดคำ/จำนวนหน้าเป็นค่าประมาณ
