# การอ้างอิง IEEE

## 1. ในเนื้อหา

- เลขในวงเล็บเหลี่ยม เรียงตามลำดับที่อ้าง **ครั้งแรก** [1], [2], …
- แหล่งเดิมใช้เลขเดิมตลอดทั้งเรื่อง
- หลายแหล่ง/ช่วงเลข: ใช้รูปแบบตาม IEEE และคู่มือวารสาร เช่น [1], [3] หรือ [1]–[3] (หรือ [1–3] ถ้าคู่มือ/งานใช้แบบนี้) — คงรูปแบบที่ต้นฉบับใช้ ไม่ห้ามการอ้างช่วงเพียงเพราะงานเก่าเคยกำหนด
- เพิ่ม ลบ หรือย้ายข้อความ → ตรวจเลขในเนื้อหากับรายการท้ายเรื่องใหม่ทั้งหมด

```bash
python scripts/ieee_refs.py บทความ.docx                         # ตรวจ
python scripts/ieee_refs.py บทความ.docx --renumber ใหม่.docx    # เรียงใหม่ (เมื่อได้รับอนุญาต)
python scripts/text_diff.py บทความ.docx ใหม่.docx --allow-renumber
```
`--renumber` แก้เลขในเนื้อหา ตาราง และภาคผนวก (ยกเว้น `--skip-appendix`) เรียงรายการใหม่ คงรูปแบบช่วง และ **ไม่ลบ** รายการที่ไม่ถูกอ้าง (ย้ายไปท้าย + รายงาน ให้ผู้ใช้ตัดสิน) ไม่รองรับรายการที่ใช้ auto-numbering ของ Word หรือการอ้างแบบ field (EndNote/Zotero/Mendeley) — กรณี field ให้ refresh ในโปรแกรมจัดการอ้างอิงของผู้ใช้แทน

## 2. ตรวจรายการท้ายเรื่อง

- อ้างแต่ไม่มีในรายการ / มีในรายการแต่ไม่ถูกอ้าง / เลขรายการไม่ต่อเนื่อง / รายการซ้ำ (ข้อความหรือ DOI)
- ผู้แต่ง ชื่อเรื่อง ปี เล่ม ฉบับ หน้า DOI เท่าที่มีข้อมูล
- DOI รูปแบบ `10.xxxx/…` และต้องตรงกับเอกสารนั้น — **ไม่สร้าง DOI หรือรายละเอียดที่ขาดขึ้นเอง** ขาด → ปล่อยว่างและรายงาน
- วันที่เข้าถึงเว็บ = วันที่ตรวจจริงในงานนี้ ห้ามคัดลอกวันที่เก่ามาอ้างว่าเพิ่งตรวจ ถ้าไม่ได้เปิดตรวจ ให้คงวันที่เดิมและรายงานว่ายังไม่ได้ตรวจ

## 3. รูปแบบตามประเภท (แนวทาง IEEE ทั่วไป ใช้คู่มือวารสารก่อนถ้าต่างกัน)

| ประเภท | รูปแบบ |
|---|---|
| วารสาร | [n] A. B. Author, “Title of article,” *Abbrev. Journal*, vol. x, no. x, pp. xx–xx, Mon. Year, doi: 10.xxxx/xxxx. |
| การประชุม | [n] A. B. Author, “Title of paper,” in *Proc. Name of Conf.*, City, Country, Year, pp. xx–xx, doi: … |
| หนังสือ | [n] A. B. Author, *Title of Book*, xth ed. City, Country: Publisher, Year. |
| บทในหนังสือ | [n] A. B. Author, “Title of chapter,” in *Title of Book*, A. Editor, Ed. City, Country: Publisher, Year, pp. xx–xx. |
| รายงาน | [n] A. B. Author, “Title of report,” Organization, City, Country, Rep. no. xxx, Year. |
| เว็บไซต์ | [n] A. B. Author/Organization, “Title of page,” Site Name. Accessed: Mon. DD, YYYY. [Online]. Available: URL |
| วิทยานิพนธ์ | [n] A. B. Author, “Title,” M.S. thesis, Dept., Univ., City, Country, Year. |

แหล่งภาษาไทย: ใช้ชื่อผู้แต่งเต็มตามต้นฉบับภาษาไทย ปี พ.ศ./ค.ศ. และการแปลชื่อเป็นอังกฤษ ให้ทำตามคู่มือวารสาร ถ้าคู่มือไม่ระบุ ให้คงตามต้นฉบับและถามผู้ใช้

## 4. การตรวจความถูกต้องของแหล่ง (เมื่อผู้ใช้ขอ)

- ตรวจข้อกล่าวอ้างกับต้นฉบับหรือแหล่งทางการ (สำนักพิมพ์ DOI resolver ฐานข้อมูลวารสาร)
- อ่านได้เพียงบทคัดย่อ / เข้าถึงต้นฉบับไม่ได้ → ระบุขอบเขตต่อรายการ เช่น "[7] ยืนยันจากบทคัดย่อเท่านั้น"
- สรุปผลแยก 3 ระดับ: ตรวจรูปแบบรายการ / ตรวจ metadata (ผู้แต่ง ปี DOI) / ตรวจเนื้อหาที่อ้าง

**งานจัดรูปแบบอย่างเดียว ≠ การตรวจความถูกต้องของแหล่งอ้างอิง** ห้ามเขียนว่า "ตรวจ IEEE ครบแล้ว" ถ้าตรวจเพียงรูปแบบรายการ ให้เขียนว่า "ตรวจลำดับเลขและรูปแบบรายการแล้ว ยังไม่ได้ยืนยันแหล่งกับต้นฉบับ"
