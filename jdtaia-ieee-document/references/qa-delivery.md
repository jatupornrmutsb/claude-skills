# ตรวจคุณภาพ เรนเดอร์ และส่งมอบ

## 1. เมื่อเข้าถึงไฟล์ไม่ได้

ค้นตามลำดับก่อนขอผู้ใช้ส่งซ้ำ:
1. ไฟล์แนบในบทสนทนา (`/mnt/user-data/uploads/` หรือชื่อไฟล์ที่แนบ)
2. โฟลเดอร์ทำงานปัจจุบันและ scratchpad
3. โฟลเดอร์บนเครื่องผู้ใช้ที่เชื่อมต่อ (device bridge) — ค้นชื่อใกล้เคียง/รุ่นอื่น
4. แหล่งที่เชื่อมต่อซึ่งเกี่ยวข้อง (Google Drive, SharePoint/OneDrive) ด้วยชื่อเรื่องหรือคำสำคัญ

พบหลายรุ่น → เปรียบเทียบชื่อรุ่น เนื้อหา (จำนวนหน้า ตาราง รายการอ้างอิง วันที่ในเอกสาร) แล้ว **แจ้งผู้ใช้ว่าใช้รุ่นใดเพราะอะไร** ห้ามเลือกตามเวลาดาวน์โหลด และห้ามใช้รุ่นเก่าแทนเงียบๆ
ไม่พบจริง → บอกว่าค้นที่ใดแล้ว และขอไฟล์ครั้งเดียวพร้อมระบุรุ่นที่ต้องการ

## 2. กระบวนการ

1. อ่านต้นฉบับและข้อกำหนดที่เกี่ยวข้องก่อนแก้
2. บันทึกสถานะก่อนแก้: `docx_audit.py --json before.json`, `ieee_refs.py`
3. แก้ในสำเนา (`apply_layout.py` + แก้ด้วยมือตาม skill docx)
4. ตรวจโครงสร้าง/ความครบถ้วน: `text_diff.py` (งาน C ต้องผ่าน), `docx_audit.py`, เปิดไฟล์ด้วย python-docx ได้, ถ้ามี `validate.py` ของ skill docx ให้รันด้วย
5. เรนเดอร์: `render_check.py --outdir <scratchpad>/render --png` (ควรยืนยันใน Microsoft Word เมื่อต้องการผลการแสดงผลใน Word)
6. ดูภาพ **ทุกหน้า** ตามรายการข้อ 3
7. แก้ → เรนเดอร์ใหม่ (วนจนไม่มีข้อบกพร่องใหม่)
8. ยืนยันจำนวนหน้าจากฉบับสุดท้าย
9. ส่งเฉพาะไฟล์ที่ผู้ใช้ขอ ไม่แนบภาพตรวจหน้า/PDF ภายในโดยอัตโนมัติ

## 3. รายการตรวจภาพหน้า

- ฟอนต์ไทยถูก สระ–วรรณยุกต์ไม่ลอย/ซ้อน
- ช่องไฟ: ไม่มีช่องห่างผิดปกติ บรรทัดสุดท้ายไม่ถูกยืด (ดู `thai-distribute.md`)
- การตัดคำไม่ตัดกลางคำ รหัส/ตัวเลขไม่แตก
- ข้อความไม่ทับกัน ตาราง/รูปไม่ล้นขอบหรือคอลัมน์ (`render_check.py` รายงานคำล้นขอบ)
- หัวตารางซ้ำเมื่อข้ามหน้า เซลล์ผสานถูก แถวไม่ถูกตัด ไม่มีแถวรวมหลุดหน้าเดี่ยว
- ชื่อรูปติดกับรูป ชื่อตารางติดกับตาราง
- หัว/ท้ายกระดาษ เลขหน้า
- section: 1/2 คอลัมน์ตามสั่ง ไม่มีหน้าว่างจาก section break

## 4. งานจัดรูปแบบอย่างเดียว: เทียบข้อความ

`text_diff.py ต้นฉบับ ผลลัพธ์` เทียบทุกย่อหน้าและทุกช่องตาราง
- `BREAK_ONLY` — เปลี่ยนเฉพาะจุดขึ้นบรรทัด (รายงานจำนวน แยกจากถ้อยคำ)
- `HIDDEN_ONLY` — ลบอักขระแฝงเดิม (เมื่อได้รับอนุญาต)
- `RENUMBER` / `REORDER` — เปลี่ยนเลขหัวข้อ/อ้างอิง/ลำดับรายการ ต้องได้รับอนุญาต (`--allow-renumber`) และรายงานแยก
- `WORDING` หรือจำนวนช่องตารางต่างกัน → **ไม่ผ่าน** ต้องกลับไปแก้ ห้ามส่ง

## 5. ข้อความส่งมอบ (แม่แบบ)

```
ประเภทงาน: จัดรูปแบบอย่างเดียว (ข้อความ/ตัวเลขไม่เปลี่ยน — ตรวจด้วยการเทียบทุกย่อหน้าและทุกช่องตาราง)
สิ่งที่แก้: …
เปลี่ยนเลข (ได้รับอนุญาต): …
จำนวนหน้า: บทความหลัก x หน้า + เอกสารอ้างอิง y หน้า (รวม z หน้า เกณฑ์ 8–10: ผ่าน/ไม่ผ่าน) | ภาคผนวก w หน้า (ไม่นับตามที่กำหนด)
  เรนเดอร์ด้วย LibreOffice, ฟอนต์ … (จริง/ทดแทน)
ยังไม่ผ่าน/ยังไม่ได้ตรวจ: …
ไฟล์: <ลิงก์>
```
ห้ามสรุปว่า "ผ่านทั้งหมด" ถ้ายังมีรายการในหัวข้อ "ยังไม่ผ่าน/ยังไม่ได้ตรวจ"

## 6. การทดสอบ Skill

เมื่อแก้สคริปต์ หรือใช้บนเครื่องใหม่: `python scripts/selftest.py --workdir <scratchpad>/selftest`
(สร้างไฟล์สมมุติเอง ไม่แตะไฟล์ผู้ใช้) ครอบคลุม: จัดรูปแบบโดยข้อความไม่เปลี่ยน, สลับ 1↔2 คอลัมน์,
ช่องไฟไทยปนอังกฤษโดยไม่เพิ่มอักขระแฝง, ตารางยาวหัวซ้ำ/เซลล์ผสาน, เพิ่มแหล่งอ้างอิงแล้วเรียงเลข,
จำนวนหน้าเกินโดยไม่ย่อเนื้อหา, ไฟล์หาย, ห้ามเขียนทับต้นฉบับ
สถานการณ์ "ข้อมูลประเมินไม่ครบ" เป็นพฤติกรรมการเขียน ทดสอบด้วยการอ่านคำแนะนำ ไม่มีสคริปต์
